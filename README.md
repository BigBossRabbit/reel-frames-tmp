# reel-frames-tmp

Scratch repo: extracted frames from short-form video, pulled apart for
analysis (story beats, cuts, on-screen text). Not a library — frames land
here when a reel needs to be read frame by frame instead of watched.

## Contents

Six frames (`u122`–`u142`), grabbed sequentially from a single reel.

## Why it exists

Video analysis is done frame-first: the deck, the caption, and the cut rhythm
are only visible when the frames are side by side. Keeping them in a repo makes
the analysis reproducible instead of a one-off folder on one machine.

See also: [rea](https://github.com/BigBossRabbit/rea) for the reverse-engineering
toolchain these frames feed.
